1). Export a PNG from Illustrator that is 400 x 400px.  
2). Upload image to https://pngtosvg.com/ and download the SVG.
3). Upload image to GitHub.  
4). Click on the file to view it. 
5). Click the RAW button in the toolbar at the top-right of the screen.
6). Copy URL from address bar.
7). Paste URL into code.
